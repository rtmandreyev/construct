# Construct v1.1.0

Models come alive. Construct 1.1 is the NetLogo release: it makes the NetLogo bridge something a
student can use in a minute and a teacher can trust. One command in NetLogo turns a run into a
construct that explains how to read it; two runs stand side by side for a lesson, and a page prints
as a worksheet. A run can leave as a film or a 3D model for Blender.

## For learners and teachers: a run in one command

**Construct for NetLogo**, a NetLogo 7 extension ([hosts/netlogo](../../hosts/netlogo/README.md)).
Add `extensions [construct]` to a model and type `construct:run` in the Command Center: it runs the
model as its buttons do, records what is worth recording, lets the run go until the model stops by
itself, chooses the view the data suits and opens the construct in the browser. A model that never
stops is drawn after 1000 runs of go, and says so; `construct:run-for 3000` runs longer. The
step-by-step commands (`construct:start`, `construct:track-…`, `construct:record`,
`construct:draw`) are there for full control. Install: unzip `construct-1.1.0.zip` into a folder
called `construct` in NetLogo's `extensions` folder (a listing in NetLogo's Extensions Manager is
planned). Recording needs only NetLogo; drawing needs Python 3.10 or newer.

**The Models Library, unattended.** Of NetLogo 7.0.4's 445 two-dimensional models, 388 now record a
run (at least two records) with no hand edits, from 256 at 1.0. Setup and go come from the model's
own buttons, turtle buttons and step buttons are understood, a model that never starts the tick
counter is recorded by steps, and a clock that moves in fractions (GasLab, system dynamics)
records every step. Most of the rest wait for a player or a classroom.

**Reading a run.** Every construct of a run carries its legend, each label shown as its part is drawn and kept
inside the window, a **How to read it** panel, and a replay bar: drag it, or press play, and the
construct is drawn up to that tick, with the tick and the run's counts beside it. The panel also
offers the counts as CSV and **Cite this run** (model, NetLogo version, seed, ticks,
Construct's version and the data lock); `construct netlogo … --csv` writes the counts at every
record. Printed, the page is a one-page worksheet with three questions for students. `construct netlogo-compare` draws two runs side by side on one time scale, for a lesson: a
slider moved, or another seed. `--view auto` chooses the view: a network where something spread or that grew, patches
that changed, turtles that switch on and off (the new **pulse**: one ring per tick, as wide as how
many are on at once, so falling into step shows as a thin column opening into wide plates), two
counts that cycle, or the agents' paths.

**Landmarks.** A construct of a run marks its moments by itself, computed from the counts: a peak ("Peak: 78
infected · tick 147"), or where something was half way and most of the way, or when half, then all, of
the fireflies flashed at once; each is marked inferred and kept under the data lock.

**Where the order forms.** Flocks form and fireflies fall into step early in a run and then hold, so a
construct of a whole long run would squeeze that moment into a few centimetres. Moving agents are
measured by their alignment and agents that switch on and off by their synchrony, and when that
order forms early, the construct is drawn over the window where it formed, and says so in its title,
its facts and How to read it (`--window whole` draws everything; the recording and the film keep the
whole run).

## Films and 3D models

**Runs as films.** A construct holds a run's shape; a film holds its motion. In Blender (the
add-on's File > Import > NetLogo Run, `construct netlogo-film run.jsonl --out film.mp4`, or
`(construct:draw "auto" "film" true)` in NetLogo), the recording itself is drawn: every agent at
every tick as moving light with a trail, in its own NetLogo colours, each link as a line of light
between its agents while it lasts, the patches as a floor that changes with them, the world's edge as
a line of light, at 30 ticks a second. Nothing is sampled, so a three-minute flock of 200 birds stays 200 birds
for three minutes. NetLogo 3D runs are recorded with their heights and fly in their box; hidden
turtles are recorded and stay unlit.

**A run as a 3D model.** `construct netlogo … --solid --glb run.glb`, or `"model" true` in NetLogo,
adds solids drawn from the recording (each turtle a sphere where it rose, a cycle as a tube, a
spread as a surface) and exports the run in its own NetLogo colours, its build replaying the run.

## For agents

**NetLogo for every agent.** The MCP server gains `construct_netlogo_instrument` and
`construct_netlogo_draw`, so Hermes or any MCP client can instrument a model, draw a run, add an art
layer, solids and colours, then compile or export it with the existing tools. The skill knows the
extension, the reading, 3D models and films.

**Critic rounds for a run (opt-in).** Construct's improvement rounds now judge a construct of a run
by its own standard: every label and milestone against the recording's facts and counts, and how a
student would read it. With GPT-6.1 Sol as the blind critic, three rounds on Virus on a Network
raised accuracy from 1 to 3 (of 3), and a planted false milestone was its first, critical defect.

## Fixes

- The ReVox A77's meter faces sat in the plane of their housings and flickered in any solid render;
  the FJ62's glasshouse shared its bottom with the body's top. Both are fixed in the examples.
- The field view's fronts are declared floating, so a run whose first front sits above the floor
  passes the audit.
- The recorder's own names no longer clash with a model's.

## Compatibility

The scene and geometry contract keeps its id, `construct/0.2`, and changes nothing that exists:
1.1 adds two optional scene keys, `presentation.labels` and `reading`, and the optional `reading` and
annotations' `phase` in geometry. The viewer changes in one way for every page: a label appears as
the build reaches its part, instead of from the first frame; otherwise a page whose scene uses none
of the new keys is the 1.0 page. NetLogo recordings gain optional header keys (`zcor`, the world's `min-pzcor` and
`max-pzcor`) and, for NetLogo 3D, each turtle's height last in its row; a 1.0 recording reads as
before. The three NetLogo examples are regenerated with readings,
so their data locks changed; their data did not. Films need Blender.
