# Construct v0.2.1

![The Sainte-Chapelle construct assembling itself](https://raw.githubusercontent.com/rtmandreyev/construct/main/docs/media/assembly-sainte-chapelle.gif)

The first public release. Construct is an agent skill and toolkit that turns a description of a
real or fictional thing into an animated holographic model, in the Measured Light style: an AI
agent writes a short scene, and Construct checks it, builds it into one web page and reviews it.

## What's included

- **Three modes, and the skill chooses.** **fast** is one careful pass in about ten minutes;
  **masterpiece** runs rounds judged by an independent critic for named subjects whose likeness
  matters; **unbounded** keeps going without the round and time limits, only when you ask. When
  you don't name a mode, the skill picks one and tells you why before it starts.
- **An independent critic.** In masterpiece mode a fresh model compares each new version with
  the best so far without knowing which is which, and only a better version is kept. You get a
  short report after every round.
- **Honest constructs.** Every fact and part is marked as verified, user-supplied, inferred or
  decorative, and the provenance view (press **P**) shows which. Unknown facts are left out.
- **A check that repairs.** Every problem comes back with where it is and how to fix it, and the
  agent repairs until the scene is clean.
- **One house style, Measured Light.** Line light over smoked glass, built part by part on screen,
  with labels drawn only from facts. Models never choose the colours.
- **A drawing guide** for detailed, sculpted constructs, and a check that warns when a main surface
  is drawn as a flat shape.
- **New shapes:** lofted car bodies and a vehicle template, towers, roofs, facades, battlements,
  ribbed shells, measured terrain and a globe from coastline data.
- **An examples gallery** of constructs made by Claude Opus, GPT-6.1 Sol and DeepSeek:
  <https://rtmandreyev.github.io/construct/>
- **Any agent, any model:** Claude Code and Hermes skills, an MCP server, and a runner for any
  OpenAI-compatible model.

## Install

```sh
git clone https://github.com/rtmandreyev/construct.git
cd construct
python3 construct_hologram/package.py --out dist
```

Then add `dist/claude-code/construct` to Claude Code (`claude --plugin-dir dist/claude-code/construct`)
or copy `dist/hermes/construct` into `~/.hermes/skills/`, and ask in plain words: *"make a construct
of a Leica M3"*. See the [README](https://github.com/rtmandreyev/construct#readme) and [USING.md](https://github.com/rtmandreyev/construct/blob/main/docs/USING.md).

## Requirements

Python 3.10 or newer, with no third-party packages. Review stills need a Chromium-family browser
you already have; videos need ffmpeg.

## Known limitations

- Glass is never tinted, and stills show the closed pose; open a construct in a browser to see it
  open.
- No imported meshes, CAD or photogrammetry; a construct is built from Construct's own shapes.
- One periodic motion per part.
- Masterpiece mode in Hermes needs a higher helper-agent limit; see
  [Troubleshooting](https://github.com/rtmandreyev/construct/blob/main/docs/TROUBLESHOOTING.md).
- Tested on macOS; review capture on Linux and Windows is untested.
