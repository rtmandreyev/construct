# Tessera Hologram Toolkit

Two layers, both independently authored (Apache-2.0), Python 3.10+ standard library only,
no model, account, API key or network service:

- **hologram-studio 0.2.0** (scene format v2, contract `tessera.hologram/0.2`): the agent
  skill. An agent writes a declarative scene (facts with certainty, parts built from a
  closed shape vocabulary, motion, presentation, animation); the toolkit validates,
  audits, compiles it deterministically and renders a self-contained animated WebGL2
  preview with review captures and video. This is the general hologram skill.
- **v1 construction sheets** (0.1.0, below): the earlier prototype compiler, its CLI and
  local MCP server. Kept unchanged and still tested.

## hologram-studio

```sh
python3 tools/hologram/cli.py new organism --output scene.json   # starters: object architecture machine organism cd book
python3 tools/hologram/cli.py check scene.json                    # validate + compile + audit
python3 tools/hologram/cli.py build scene.json --out out/         # geometry.json, hologram.html, audit
python3 tools/hologram/cli.py review scene.json --out out/        # + review/*.png contact sheets, hero, still
python3 tools/hologram/cli.py video scene.json --out out/clip.mp4 --seconds 20
```

**Any model.** `check --json` (or `diagnose.diagnose_text`) returns every problem with a
JSON path, a code and a fix hint, plus `repair_text` to send back to the model that wrote the
draft. **The simple path:** `params --list`, `params <archetype> --variant <v>`, fill in the
facts; `check`/`build`/`review` accept the parameter document and a builder draws a case
(jewel, slim, digipak, box set), a book (hardcover, paperback), a guitar (electric, acoustic,
bass), a synth or a vessel (bottle, can, glass). `prompts --out dir` writes the any-model
package (`system.md`, `params.md`, `scene.md`, `repair.md`, `params.schema.json`); the
committed copy is `prompts/`. `evaluation/` holds synthetic tasks and a scorer that needs no
model or key: `python3 -m tools.hologram.evaluation.score <run folders>`.

`build --frame z-up` also writes the geometry in a Z-up frame; `build --v1` writes a v1
downgrade. Open `hologram.html` in any WebGL2 browser (no server). Keys: drag/wheel to
orbit, 1–6 views, L labels, P provenance, M reduced motion, R replay, space pause. URL parameters
`t`, `view`, `motion=reduced`, `mode=provenance`, `labels`, `ui`, `sheet` and `open` (0..1, a
fixed opening) reproduce any frame exactly.

### Install the skill

`python3 tools/hologram/package.py --out <empty folder>` writes two self-contained
packages (runtime, references, examples, LICENSE, NOTICE, hashed MANIFEST.json):

- **Hermes**: `<out>/hermes/hologram-studio/`. Copy it into `~/.hermes/skills/` (or a
  project's `.hermes/skills/` and run `hermes skills trust` there); the body uses
  `${HERMES_SKILL_DIR}`.
- **Claude Code**: `<out>/claude-code/hologram-studio/` is a plugin
  (`.claude-plugin/plugin.json` + `skills/hologram-studio/`). Try it for one session with
  `claude --plugin-dir <out>/claude-code/hologram-studio`, or copy
  `skills/hologram-studio` into a project's `.claude/skills/` (or `~/.claude/skills/`); the
  body uses `${CLAUDE_SKILL_DIR}`. Invoked automatically or as
  `/hologram-studio:hologram-studio` from the plugin.

The packager never installs anything or changes host configuration; copying is yours.

### Requirements and notices

Python 3.10+. Captures need a Chromium-family browser already installed (Chrome,
Chromium, Edge, Brave, or `HOLOGRAM_CHROME=/path`); GPU first, SwiftShader fallback.
Video needs ffmpeg. Nothing is downloaded. No third-party code, fonts, shaders, models or
datasets are bundled; the viewer uses system fonts. It recreates the look and method of
NODE's Measured Light holograms without any NODE code, fonts or assets. The example
covers are synthetic (generated by `png.py`) and labelled as generated decoration.

### Verified

- Unit tests: `test_scene.py` (examples, validation, compilation, audit, build, CLI,
  capture smoke test) and `test_package.py` (frontmatter, manifests, references, no
  private material, a run from an isolated copy).
- Hermes: its own skill loader (`agent.skill_utils`, `agent.skill_preprocessing`)
  discovers the package, parses the frontmatter and resolves `${HERMES_SKILL_DIR}` to the
  runtime. A live Hermes chat with the skill was **not** run: isolation needs a profile or
  `hermes skills trust`, both global configuration changes outside this assignment.
- Claude Code 2.1.299: `claude plugin validate --strict` passes (isolated
  `CLAUDE_CONFIG_DIR`). A fresh agent completed the loop from the package alone (see the
  handoff). A live `claude -p --plugin-dir` run was **not** made here (an isolated config
  has no login).
- Tested on macOS (Apple Silicon, Chrome). Linux and Windows are untested.

### Limitations

- One periodic motion per part and no nested periodic motion: a fan's blades can spin or
  its head can oscillate, not both. One-shot articulations (hinge, slide, lift, turn) do
  nest, and a part can both open and keep moving. Nothing is rigged or skinned.
- Shapes are a closed procedural vocabulary: no imported meshes, CAD or photogrammetry,
  no boolean operations; organic subjects are approximations from ellipsoids, lathes and tubes.
- Artwork is a flat image on a plane (PNG, JPEG or WebP bytes the user supplied, hashed).
- The audit checks support by bounding boxes and certainty claims; likeness and beauty
  are judged by the agent's visual review, which depends on a model that can read images.
- Quality depends on the authoring model; the toolkit guarantees validity, determinism and
  honesty labels, not likeness.

## v1 construction sheets (prototype 0.1.0)

### Use

From any directory, replace `/path/to` with the actual toolkit location:

```sh
python3 /path/to/hologram/cli.py template cd --output cd.json
python3 /path/to/hologram/cli.py validate cd.json
python3 /path/to/hologram/cli.py compile cd.json --output geometry.json
```

In the Tessera repository the directory is `tools/hologram`; module invocation
`python3 -m tools.hologram ...` also works from the repository root. Output files
refuse overwrite unless `--force` is explicit. Validate local artwork bytes with
`--asset-root /path/to/assets` on validate/compile; no download or image decoder
is included. The default validates asset declarations without reading bytes.

### Connect to an MCP host

Launch `python3 /absolute/path/to/hologram/server.py` as a **stdio** server.
For clients accepting the usual `mcpServers` structure, adapt this example to
their documented configuration location (this package does not modify it):

```json
{"mcpServers":{"tessera-hologram":{"command":"/absolute/path/to/python3","args":["/absolute/path/to/hologram/server.py"]}}}
```

Tools: `hologram_template`, `hologram_validate`, `hologram_compile`. They only
operate on JSON supplied in the request: no file access, shell, model calls or
networking. CLI file access is separate. Newline-delimited JSON-RPC uses MCP
protocol version 2025-11-25. Initialization, tool discovery and calls are tested
with a protocol client; actual Hermes/Claude host compatibility is still a gate.
Keep stdout reserved for protocol messages. No API key belongs in this server.

The model runs in the host chosen by the user. A capable model can author sheets;
quality varies, and no claim is made that every LLM will produce valid or accurate
objects. The compiler is deterministic and rejects malformed sheets. The skill
at `skills/create-hologram/SKILL.md` provides a portable authoring workflow.

### Contract

See `schema.json`, the examples and the skill's contract reference. Preserve
facts and their sources separately from inferred geometry and decorative motion.
Verified geometry requires a source. Generic templates are illustrative; the CD
template is a generic jewel case, never an identification of a physical edition.
The compiler carries a canonical source-sheet hash, facts and per-part provenance.
Applications must retain the actual source sheet too; a hash cannot reconstruct it.

Artwork declarations require an asset ID, relative path, SHA-256, media type and
rights statement. A hash and a rights string are declarations, not proof of rights.
Artwork binds to a box front face and compiles to UV quads. The atlas study currently
renders line geometry only; texture display/decoding remains future integration.
No generated approximation may be presented as the authentic album cover.

Budgets: 1 MiB input, 4 MiB output, 128 parts, 128 scalar facts, 32 assets,
20,000 compiled segments; staged assembly at most 5 seconds. No shader source,
script, executable payload, remote URL fetch, or filesystem path outside an explicit
asset root. The implementation validator is authoritative for cross-field rules.

### Verify

From the repository root: `python3 -m unittest tools.hologram.test_hologram
tools.hologram.test_scene tools.hologram.test_package tools.catalog.test_catalog_csv
tools.test_tool_regressions`. The capture smoke test is skipped without a browser. For a
standalone toolkit, run `python3 -m unittest hologram.test_hologram` from its containing
directory. Only synthetic examples and fixtures are distributed.
