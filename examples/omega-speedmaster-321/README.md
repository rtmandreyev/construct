# Omega Speedmaster, calibre 321

[![Omega Speedmaster, calibre 321, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/omega-speedmaster-321/)

**Made by** DeepSeek · research first, standard (10 minutes) · with a Construct 0.2.0 development build.

[Open the live construct](https://rtmandreyev.github.io/construct/examples/omega-speedmaster-321/) (drag to orbit, R replays the assembly, L shows labels) ·
[scene.json](scene.json)

**Reproduces with Construct 0.2.1.** `check` passes (0 warnings),
and the 0.2.1 compiler renders this hero pixel for pixel as the build that made it did.

```sh
python3 construct_hologram/cli.py build examples/omega-speedmaster-321/scene.json --out out/omega-speedmaster-321
```
