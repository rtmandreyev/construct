# Sydney Opera House

[![Sydney Opera House, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/sydney-opera-house/)

**masterpiece · GPT-6.1 Sol**

[Open the live construct](https://rtmandreyev.github.io/construct/examples/sydney-opera-house/): drag to orbit, R replays the assembly, L shows
labels. The scene it was built from: [scene.json](scene.json).

Build it yourself from a checkout of Construct:

```sh
python3 construct_hologram/cli.py build examples/sydney-opera-house/scene.json --out out/sydney-opera-house
```
