[Open the live construct](https://rtmandreyev.github.io/construct/examples/porsche-911-964/): drag to orbit, R replays the assembly, L shows
labels. The scene it was built from: [scene.json](scene.json).

Build it yourself from a checkout of Construct:

```sh
python3 construct_hologram/cli.py build examples/porsche-911-964/scene.json --out out/porsche-911-964
```
