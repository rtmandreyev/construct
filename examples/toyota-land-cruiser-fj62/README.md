# Toyota Land Cruiser FJ62

[![Toyota Land Cruiser FJ62, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/toyota-land-cruiser-fj62/)

**masterpiece · Claude Opus**

[Open the live construct](https://rtmandreyev.github.io/construct/examples/toyota-land-cruiser-fj62/): drag to orbit, R replays the assembly, L shows
labels. The scene it was built from: [scene.json](scene.json).

Build it yourself from a checkout of Construct:

```sh
python3 construct_hologram/cli.py build examples/toyota-land-cruiser-fj62/scene.json --out out/toyota-land-cruiser-fj62
```
