# Andromeda Galaxy (M31)

[![Andromeda Galaxy (M31), a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/andromeda-galaxy/)

**masterpiece · DeepSeek V4.1 Flash**

[Open the live construct](https://rtmandreyev.github.io/construct/examples/andromeda-galaxy/): drag to orbit, R replays the assembly, L shows
labels. The scene it was built from: [scene.json](scene.json).

Build it yourself from a checkout of Construct:

```sh
python3 construct_hologram/cli.py build examples/andromeda-galaxy/scene.json --out out/andromeda-galaxy
```
