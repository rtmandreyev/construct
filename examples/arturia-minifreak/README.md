# Arturia MiniFreak

[![Arturia MiniFreak, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/arturia-minifreak/)

**Made by** DeepSeek · a single first pass · with a Construct 0.2.0 development build.

[Open the live construct](https://rtmandreyev.github.io/construct/examples/arturia-minifreak/) (drag to orbit, R replays the assembly, L shows labels) ·
[scene.json](scene.json)

**Reproduces with Construct 0.2.1.** `check` passes (0 warnings),
and the 0.2.1 compiler renders this hero pixel for pixel as the build that made it did.

```sh
python3 construct_hologram/cli.py build examples/arturia-minifreak/scene.json --out out/arturia-minifreak
```
