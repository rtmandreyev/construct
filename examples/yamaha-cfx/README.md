# Yamaha CFX

[![Yamaha CFX, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/yamaha-cfx/)

**Made by** DeepSeek · standard (10 minutes) · with Construct 0.2.0.

[Open the live construct](https://rtmandreyev.github.io/construct/examples/yamaha-cfx/) (drag to orbit, R replays the assembly, L shows labels) ·
[scene.json](scene.json)

**Reproduces with Construct 0.2.1.** `check` passes (3 warnings: clutter, self-graded, tiny),
and the 0.2.1 compiler renders this hero pixel for pixel as the build that made it did.

```sh
python3 construct_hologram/cli.py build examples/yamaha-cfx/scene.json --out out/yamaha-cfx
```
