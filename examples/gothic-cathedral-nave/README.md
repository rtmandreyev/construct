# Gothic cathedral nave

[![Gothic cathedral nave, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/gothic-cathedral-nave/)

**fast · GPT-6.1 Sol**

[Open the live construct](https://rtmandreyev.github.io/construct/examples/gothic-cathedral-nave/): drag to orbit, R replays the assembly, L shows
labels. The scene it was built from: [scene.json](scene.json).

Build it yourself from a checkout of Construct:

```sh
python3 construct_hologram/cli.py build examples/gothic-cathedral-nave/scene.json --out out/gothic-cathedral-nave
```
