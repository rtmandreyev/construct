# Ferrari F40

[![Ferrari F40, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/ferrari-f40/)

**masterpiece · GPT-6.1 Sol**

[Open the live construct](https://rtmandreyev.github.io/construct/examples/ferrari-f40/): drag to orbit, R replays the assembly, L shows
labels. The scene it was built from: [scene.json](scene.json).

Build it yourself from a checkout of Construct:

```sh
python3 construct_hologram/cli.py build examples/ferrari-f40/scene.json --out out/ferrari-f40
```
