# Duomo di Milano

[![Duomo di Milano, a holographic construct](hero.jpg)](https://rtmandreyev.github.io/construct/examples/duomo-di-milano/)

**Made by** Claude Opus · masterpiece rounds, round 6 · with a Construct 0.2.1 development build.

[Open the live construct](https://rtmandreyev.github.io/construct/examples/duomo-di-milano/) (drag to orbit, R replays the assembly, L shows labels) ·
[scene.json](scene.json)

**Reproduces with Construct 0.2.1.** `check` passes (20 warnings: tiny),
and the 0.2.1 compiler renders this hero pixel for pixel as the build that made it did.

```sh
python3 construct_hologram/cli.py build examples/duomo-di-milano/scene.json --out out/duomo-di-milano
```
